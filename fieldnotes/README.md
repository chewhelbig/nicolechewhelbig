# FieldNotes

A Gestalt-informed companion that turns a session narrative into structured clinical notes (Gestalt SOAP, supervisor questions, contact-cycle roadmap, unfinished business), an optional supervision reflection, and an ongoing supervision conversation.

Single static page. Runs on the user's own Anthropic API key (Claude Opus). Nothing is stored: the key lives only in the user's browser, and sessions are never saved.

Live at: https://nicolechewhelbig.com/fieldnotes/

Files: index.html is the app; getting-started.html is a non-technical walkthrough for getting an Anthropic key.
